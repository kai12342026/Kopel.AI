# אפרת · Architect PRD Builder

שלב 3 מתוך 3 · [לכל הסוכנים](README.md)

הופך קייס עסקי למסמך אפיון (PRD) שאפשר לתת ל-Claude Code ולהתחיל לבנות ממנו.

## מה הוא עושה

- מתרגם את הקייס למקרי שימוש ולדרישות.
- מפרט מקרי קצה, כדי שלא יתגלו רק בזמן הבנייה.
- מסמן הנחות פתוחות, כדי שיהיה ברור מה עוד לא הוחלט.

## מה נותנים לו

את הקייס העסקי מהשלב הקודם, או קייס שכתבתם בעצמכם.

## מה מקבלים

מסמך PRD: מקרי שימוש, דרישות, מקרי קצה והנחות פתוחות.

## למי זה מתאים

למי שבונה עם Claude Code ורוצה להתחיל ממסמך ברור, ולא משיחה ארוכה שבה הדרישות מתגלות תוך כדי.
