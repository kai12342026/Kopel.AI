# הסוכנים שלי

לכל סוכן יש שם, תפקיד וכרטיס שמסביר מה נותנים לו ומה מקבלים. חלק מהם פתוחים לכולם, וחלק דורשים בקשת גישה.

## סוכנים פתוחים

ההנחיות המלאות מפורסמות כאן, ואפשר להעתיק אותן לשיחה או להתקין אותן כסקיל.

| סוכן | מה הוא עושה |
|---|---|
| [מיסטר קופי](mr-copy.md) | קופי שיווקי, כותרות, מיקרו-קופי, סלוגנים ודפי נחיתה |
| [עדולה](adula.md) | ליווי הורים לתינוקות עד גיל שנה: שינה, הנקה וסדר יום |

## שרשרת ה-Architect: בבקשת גישה

שלושה סוכנים, כל אחד עושה שלב אחד בדרך מרעיון למסמך שאפשר לבנות ממנו. בין שלב לשלב עוצרים ובודקים: זה נכון? זה מספיק?

גילוי ← קייס עסקי ← מסמך אפיון

| סוכן | מה נכנס | מה יוצא |
|---|---|---|
| [נגה · Discovery & Solution Architect](discovery-solution-architect.md) | שיחה עם בעל או בעלת עסק | מיפוי של העסק, רשימת פתרונות מדורגת ומפת דרכים |
| [בני · Architect Case Builder](case-builder.md) | רעיון גולמי, במשפט אחד או במסמך שלם | קייס עסקי מסודר: בעיה, משתמשים, מסכים, תהליכים ויכולות AI |
| [אפרת · Architect PRD Builder](prd-builder.md) | הקייס העסקי | מסמך אפיון (PRD) שאפשר לתת ל-Claude Code |

ההנחיות המלאות של השלושה לא מפורסמות כאן. גרסה פתוחה וקצרה של השלב הראשון נמצאת בסקיל [discovery-interview](../skills/discovery-interview/SKILL.md), ואפשר להתחיל ממנה כבר עכשיו.

### איך מקבלים גישה

פותחים [בקשת גישה](https://github.com/kai12342026/Kopel.AI/issues/new?template=agent-access.md) וכותבים איזה סוכן מעניין אתכם ולמה. אני חוזרת לכל בקשה.
