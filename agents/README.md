# שלושת סוכני ה-Architect

שלושה סוכנים, כל אחד עושה שלב אחד בדרך מרעיון למסמך שאפשר לבנות ממנו. בין שלב לשלב עוצרים ובודקים: זה נכון? זה מספיק?

גילוי ← קייס עסקי ← מסמך אפיון

| סוכן | מה נכנס | מה יוצא |
|---|---|---|
| [Discovery & Solution Architect](discovery-solution-architect.md) | שיחה עם בעל או בעלת עסק | מיפוי של העסק, רשימת פתרונות מדורגת ומפת דרכים |
| [Architect Case Builder](case-builder.md) | רעיון גולמי, במשפט אחד או במסמך שלם | קייס עסקי מסודר: בעיה, משתמשים, מסכים, תהליכים ויכולות AI |
| [Architect PRD Builder](prd-builder.md) | הקייס העסקי | מסמך אפיון (PRD) שאפשר לתת ל-Claude Code |

## מה יש כאן ומה אין

בתיקייה הזו יש כרטיס לכל סוכן: מה הוא עושה, מה נותנים לו ומה מקבלים. ההנחיות המלאות של הסוכנים לא מפורסמות כאן.

גרסה פתוחה וקצרה של השלב הראשון נמצאת בסקיל [discovery-interview](../skills/discovery-interview/SKILL.md), ואפשר להתחיל ממנה כבר עכשיו.
