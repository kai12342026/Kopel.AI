# פרומפט: לבנות סקיל משלכם

מדביקים ב-Claude Code, ממלאים את הסוגריים המרובעים, ו-Claude כותב את הסקיל.

```
צור לי סקיל בשם [שם] ב-Claude Code.
מתי להפעיל אותו: [כשאני כותבת ... / כשמבקשים ...].
מה הוא עושה, צעד אחר צעד: [1. ... 2. ... 3. ...].
מה אסור לו לעשות: [למשל: לא לשלוח הודעות, לא למחוק קבצים].
איך נראה תוצר טוב: [דוגמה].
לפני שאתה כותב את הקובץ, שאל אותי שאלה אחת אם משהו לא ברור.
```

## מה הופך סקיל לטוב

- **תיאור שמסביר מתי.** Claude מחליט אם לטעון סקיל לפי שורת התיאור שלו. כותבים בה את המילים שתגידו כשתצטרכו אותו.
- **גבולות כתובים.** מה אסור חשוב כמו מה מותר, בעיקר בפעולות שאי אפשר לבטל: שליחה, מחיקה, פרסום.
- **דוגמה לתוצר.** דוגמה אחת טובה שווה יותר מעמוד של הסברים.
- **קצר.** סקיל שנטען בכל שיחה עולה בקשב. מה שלא משנה את ההתנהגות יורד.
