# פרומפטים: מה עושים עם דוח insights

`/insights` היא פקודה מובנית ב-Claude Code. היא כותבת דוח על השבועות האחרונים: איפה סשנים נתקעו ומה חוזר על עצמו. אחרי שיש דוח, מריצים עליו אחד משני הפרומפטים האלה ב-Claude Code.

## הופכים המלצות לכללים ב-CLAUDE.md

```
קרא את הדוח האחרון של insights בקובץ:
~/.claude/usage-data/report.html

1. מצא את כל ההמלצות להוספה ל-CLAUDE.md ואת הטעויות שחוזרות יותר מפעם אחת.
2. נסח מהן הוראות קצרות וברורות, שורה אחת לכל הוראה.
3. הצג לי את הרשימה ותחכה לאישור שלי לפני שאתה משנה קובץ כלשהו.
4. אחרי האישור, הוסף רק את ההוראות שאישרתי ל-CLAUDE.md, בלי למחוק שום דבר קיים.
```

## הופכים משימה שחוזרת לסקיל

```
לפי הדוח בקובץ:
~/.claude/usage-data/report.html

1. מצא את 3 המשימות שאני מבקש הכי הרבה פעמים, באותו ניסוח או כמעט באותו ניסוח.
2. לכל אחת, כתוב לי במשפט אחד מה הסקיל יעשה וכמה זמן הוא יחסוך.
3. אחרי שאבחר אחת, בנה לה סקיל עם שם קצר, תיאור ברור והוראות צעד אחר צעד, ותראה לי אותו לפני שמירה.
```

את הסקיל שנוצר כדאי לבדוק לפי [הפרומפט לבניית סקיל](new-skill.md): תיאור שמסביר מתי, גבולות כתובים, דוגמה לתוצר.
