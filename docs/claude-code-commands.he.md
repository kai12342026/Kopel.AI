# פקודות ודגלים ב-Claude Code: מדריך בעברית

פקודת סלאש מקלידים בתחילת הודעה בתוך סשן, למשל `/plan`. דגל מוסיפים לפקודה `claude` כשפותחים סשן מהטרמינל, למשל `claude --continue`. כל מה שכתוב אחרי שם הפקודה עובר אליה כארגומנט.

סימנים בטבלאות: `<arg>` הוא ארגומנט חובה, `[arg]` הוא ארגומנט רשות. **סקיל** מסמן פקודה שהיא בעצם הנחיות שנמסרות ל-Claude, כמו סקיל שכותבים לבד.

עודכן בנובמבר 2026 לפי [התיעוד הרשמי](https://code.claude.com/docs/en/commands). לא כל פקודה מופיעה אצל כולם: חלק תלויות בתוכנית, במערכת ההפעלה ובגרסה. מקלידים `/` בתוך סשן כדי לראות מה זמין אצלכם.

## מסלול עבודה טיפוסי

1. **ריפו חדש.** `/init` יוצר קובץ `CLAUDE.md` עם הנחיות לפרויקט, ו-`/memory` פותח אותו לעריכה.
2. **לפני שינוי גדול.** `/plan` נכנס למצב תכנון: Claude מציע תוכנית ולא נוגע בקבצים עד שמאשרים.
3. **כשהשיחה מתארכת.** `/context` מראה מה ממלא את חלון ההקשר, ו-`/compact` מסכם את השיחה ומפנה מקום.
4. **לפני שמגישים.** `/diff` מראה מה השתנה, ו-`/code-review` בודק את השינוי ומחפש באגים.
5. **בין משימות.** `/clear` פותח שיחה נקייה, ו-`/resume` חוזר לשיחה קודמת.

## התחלת עבודה בפרויקט

| פקודה | מה היא עושה |
|---|---|
| `/init` | סורקת את הפרויקט וכותבת `CLAUDE.md`: מבנה, שפה, מוסכמות. הפקודה הראשונה בריפו חדש. |
| `/memory` | עריכת קובצי `CLAUDE.md`, הפעלה וכיבוי של זיכרון אוטומטי וצפייה במה שנשמר בו. |
| `/add-dir <path>` | מוסיפה תיקייה נוספת שמותר לקרוא ולערוך בה בסשן הזה. |
| `/cd <path>` | מעבירה את הסשן לתיקייה אחרת ושומרת על השיחה. |
| `/import [codex\|gemini\|cursor]` | מייבאת הגדרות, סקילים ושרתי MCP מכלי קוד אחרים שמותקנים במחשב. |
| `/team-onboarding` | כותבת מדריך קליטה לחבר צוות, לפי השימוש שלכם ב-30 הימים האחרונים. |

## ניהול השיחה

| פקודה | מה היא עושה |
|---|---|
| `/clear [name]` | שיחה חדשה עם הקשר ריק. השם, אם נותנים, מסמן את השיחה הקודמת ברשימת `/resume`. גם `/new`, `/reset`. |
| `/compact [instructions]` | מסכמת את השיחה עד כאן כדי לפנות מקום. אפשר לכתוב על מה להתמקד בסיכום. |
| `/autocompact [auto\|<tokens>]` | קובעת מתי הסיכום האוטומטי נכנס לפעולה. |
| `/context [all]` | מפה צבעונית של מה שממלא את חלון ההקשר, עם המלצות לפינוי. |
| `/resume [session]` | חזרה לשיחה קודמת לפי שם או מזהה, או בחירה מרשימה. גם `/continue`. |
| `/rename [name]` | שם לסשן, שמופיע בשורת הפקודה וברשימת השיחות. |
| `/branch [name]` | פיצול של השיחה מהנקודה הזו, כדי לנסות כיוון אחר בלי לאבד את המקורי. |
| `/rewind` | חזרה של הקוד והשיחה לנקודה קודמת. גם `/undo`, `/checkpoint`. |
| `/btw [question]` | שאלת צד על הסשן, שלא נכנסת להיסטוריה של השיחה. |
| `/recap` | סיכום של שורה אחת על מה שקרה בסשן. |
| `/copy [N]` | העתקת התשובה האחרונה, או התשובה ה-N מהסוף. |
| `/export [filename]` | ייצוא השיחה כטקסט לקובץ או ללוח. |
| `/exit` | יציאה. גם `/quit`. |

## דגלים לפקודה `claude`

| דגל | מה הוא עושה | דוגמה |
|---|---|---|
| `-c`, `--continue` | ממשיך את השיחה האחרונה בתיקייה הזו. | `claude -c` |
| `-r`, `--resume [name]` | ממשיך שיחה לפי שם או מזהה, או פותח רשימה. | `claude -r auth-refactor` |
| `-n`, `--name <name>` | שם לסשן, כדי למצוא אותו אחר כך. | `claude -n "דף נחיתה"` |
| `--fork-session` | עם `--resume`: ממשיך מעותק ולא מהשיחה המקורית. | `claude -r abc --fork-session` |
| `-w`, `--worktree [name]` | פותח סשן בעותק נפרד של הריפו, בענף משלו. | `claude -w fix-login` |
| `--add-dir <path>` | תיקייה נוספת שמותר לעבוד בה. | `claude --add-dir ../shared` |
| `--model <name>` | מודל לסשן הזה. | `claude --model sonnet` |
| `--effort <level>` | רמת חשיבה לסשן הזה. | `claude --effort high` |
| `--permission-mode <mode>` | מצב הרשאות בפתיחה, למשל `plan`. | `claude --permission-mode plan` |
| `--allowedTools "<list>"` | כלים שרצים בלי לשאול. | `claude --allowedTools "Read"` |
| `--append-system-prompt "<text>"` | כללים שמתווספים להנחיות של Claude לסשן הזה. | `claude --append-system-prompt "כתוב בעברית"` |
| `--bg "<prompt>"` | מתחיל סשן ברקע ומחזיר את הטרמינל. | `claude --bg "בדוק את הטסט שנופל"` |
| `--chrome` | מפעיל עבודה עם דפדפן Chrome. | `claude --chrome` |
| `--remote-control` | סשן שאפשר להמשיך גם מהטלפון. | `claude --rc` |
| `-p`, `--print "<prompt>"` | שאלה אחת בלי שיחה: עונה ויוצא. טוב לסקריפטים. | `claude -p "סכם את README"` |
| `--output-format <fmt>` | עם `-p`: `text`, `json` או `stream-json`. | `claude -p "..." --output-format json` |
| `--max-turns <n>` | עם `-p`: הגבלת מספר הסבבים. | `claude -p "..." --max-turns 3` |
| `--max-budget-usd <amt>` | עם `-p`: עצירה כשההוצאה המוערכת מגיעה לסכום. | `claude -p "..." --max-budget-usd 5` |
| `--debug` | לוגים מפורטים לאבחון. | `claude --debug` |

ולא מהסשן, אלא מהטרמינל: `claude update` מעדכן גרסה, `claude doctor` בודק את ההתקנה, ו-`claude agents` מציג את כל הסשנים שרצים ברקע.

### על `--dangerously-skip-permissions`

הדגל מבטל את כל בקשות האישור, כולל לפני מחיקה ושליחה. השם שלו מזהיר בצדק. משתמשים בו רק בסביבה מבודדת, לא בפרויקט עם לקוחות ולא במחשב שיש בו מפתחות. ברוב המקרים `--permission-mode acceptEdits` או `/fewer-permission-prompts` מספיקים.
