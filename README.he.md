# Kopel.AI

סקילים ופרומפטים ל-Claude, כתובים בעברית, מתוך עבודה עם לקוחות.

אני עדי קופל לוי, מנהלת מוצר שבונה פתרונות AI לעסקים קטנים. אלה הנחיות שכתבתי לסוכנים שלי. כל אחת היא קובץ טקסט אחד שקוראים בשתי דקות, ואפשר להעתיק אותו לשיחה או להתקין אותו כסקיל.

[Read in English](README.md)

## הסוכנים שלי

שלושה סוכנים שמובילים מרעיון למסמך אפיון, כל אחד בשלב אחד: גילוי ← קייס עסקי ← מסמך אפיון. לכל אחד יש [כרטיס](agents/README.md) שמסביר מה הוא עושה, מה נותנים לו ומה מקבלים, ושם גם מבקשים גישה.

## איך מתחילים

**לנסות בלי להתקין.** פותחים `SKILL.md`, מעתיקים את מה שמתחת לכותרת, ומדביקים בתחילת שיחה.

**לשמור ב-claude.ai.** פותחים Project ומדביקים את הסקיל בהנחיות הפרויקט. כל שיחה בפרויקט מתחילה איתו.

**להתקין ב-Claude Code.**

```bash
git clone https://github.com/kai12342026/Kopel.AI.git
```

```bash
cp -r Kopel.AI/skills/discovery-interview ~/.claude/skills/
```

Claude טוען סקיל כשהבקשה שלכם מתאימה לתיאור שלו. ההסבר המלא: [docs/install.he.md](docs/install.he.md).

## איך הסקילים כתובים

- **טקסט בלבד.** בלי סקריפטים ובלי הורדות. אפשר לבדוק כל סקיל בקריאה. היוצא מן הכלל הוא `sticky-scroll-steps`, שמצורף אליו רכיב React להעתקה לפרויקט שלכם.
- **גבולות כתובים.** כל סקיל אומר מה אסור לו, למשל להציע פתרון באמצע ראיון, או לדחוף לענף שמפעיל פריסה.
- **קצרים.** סקיל עולה בקשב בכל פעם שהוא נטען. שורה שלא משנה התנהגות יורדת.
- **מתוך עבודה.** כל אחד מהם נולד בפרויקט של לקוח או בהרצאה, ומתעדכן כשהוא נכשל.
