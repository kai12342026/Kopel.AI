# Kopel.AI

סקילים ופרומפטים ל-Claude, כתובים בעברית, מתוך עבודה עם לקוחות.

אני עדי קופל לוי, מנהלת מוצר שבונה פתרונות AI לעסקים קטנים. אלה הנחיות שכתבתי לסוכנים שלי. כל אחת היא קובץ טקסט אחד שקוראים בשתי דקות, ואפשר להעתיק אותו לשיחה או להתקין אותו כסקיל.

[Read in English](README.md)

## מה יש כאן

| סקיל | מה הוא עושה |
|---|---|
| [discovery-interview](skills/discovery-interview/SKILL.md) | מראיין בעל או בעלת עסק לפני שבונים משהו. שאלה אחת בכל פעם, בלי פתרונות, ובסוף קייס עסקי קצר. |
| [human-writing-he](skills/human-writing-he/SKILL.md) | כללי כתיבה שגורמים לטקסט בעברית לא להישמע כמו מודל: פיסוק, פתיחים, מילות מילוי וחמש שאלות לבדיקה לפני שליחה. |
| [site-copy-he](skills/site-copy-he/SKILL.md) | כללים לכתיבה שיווקית, לתוכן של אתר ולטקסט על מסך. כולל מבחן למשפטים גנריים, ודפוסים לכפתורים, לשגיאות ולמסכים ריקים. |
| [presentation-craft](skills/presentation-craft/SKILL.md) | איך בונים מצגת שמציגים ולא קוראים: מעט מאוד טקסט על השקף, ומסמך נפרד "מה לומר בכל שקף" עם הוראות ביצוע. |
| [save](skills/save/SKILL.md) | סוגר שיחה ארוכה ב-Claude Code: כותב מסמך המשך, מעדכן את רשימת המשימות, שומר גיבוי בגיט ומחזיר פרומפט קצר שממנו השיחה הבאה מתחילה. |

ועוד: [פרומפט לבניית סקיל משלכם](prompts/new-skill.md).

## איך מתחילים

**לנסות בלי להתקין.** פותחים `SKILL.md`, מעתיקים את מה שמתחת לכותרת, ומדביקים בתחילת שיחה.

**לשמור ב-claude.ai.** פותחים Project ומדביקים את הסקיל בהנחיות הפרויקט. כל שיחה בפרויקט מתחילה איתו.

**להתקין ב-Claude Code.**

```bash
git clone https://github.com/kai12342026/Kopel.AI.git
```

```bash
cp -r Kopel.AI/skills/discovery-interview ~/.claude/skills/
```

Claude טוען סקיל כשהבקשה שלכם מתאימה לתיאור שלו. ההסבר המלא: [docs/install.he.md](docs/install.he.md).

## איך הסקילים כתובים

- **טקסט בלבד.** בלי סקריפטים ובלי הורדות. אפשר לבדוק כל סקיל בקריאה.
- **גבולות כתובים.** כל סקיל אומר מה אסור לו, למשל להציע פתרון באמצע ראיון, או לדחוף לענף שמפעיל פריסה.
- **קצרים.** סקיל עולה בקשב בכל פעם שהוא נטען. שורה שלא משנה התנהגות יורדת.
- **מתוך עבודה.** כל אחד מהם נולד בפרויקט של לקוח או בהרצאה, ומתעדכן כשהוא נכשל.

## מה בדרך

- סוכן Business case, שהופך תיאור מבולגן לבעיה, משתמשים, מטרות, אילוצים ומדדי הצלחה.
- סוכן אפיון, שהופך את הקייס למסמך PRD.
- סוכן תמלול, שמחזיר מפגישה סיכום, משימות וטיוטת הודעה ללקוח.

כדי לקבל עדכון כשהם עולים, לוחצים Watch על הריפו.
