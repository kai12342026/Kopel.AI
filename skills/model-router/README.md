# model-router

**בקצרה:** סקיל שמחליט באיזה מודל Claude להריץ כל משימה, כדי שהמודל היקר ביותר ירוץ רק איפה שבאמת צריך אותו.

## הבעיה

סשנים ארוכים רצים כברירת מחדל על המודל החזק והיקר ביותר, גם כשמדובר בסיכום, בתיקון CSS או בעדכון רשימת משימות. המכסה נגמרת באמצע העבודה, והמשימות הקשות באמת נשארות בלי מכסה.

## מה הסקיל עושה

- מסווג משימה לפי סוג ובוחר מודל אחד מארבעה.
- נותן ברירת מחדל ברורה לרגעי ספק.
- אומר מתי לעלות מודל אחרי ניסיון שנכשל, ומתי לא.
- מסביר איך מעבירים את הבחירה להפעלת תת-סוכן או סשן משנה.
- מחזיר למשתמשת שורה אחת שמסבירה את הבחירה.

## מה לא כאן

הטבלה המלאה, כללי העלייה והנוסח המדויק לא מפורסמים בעמוד הזה. הם כתובים לפי מבנה העבודה שלי, ולא מתאימים להעתקה as-is.
