# טוגל שפות: שני חוקים קשיחים

בכל פרויקט רב-לשוני. שני החוקים האלה נלמדו בדרך הקשה בארבעה פרויקטים,
ובאחד מהם טוגל השפה **זז 890 פיקסלים** בין השפות לפני התיקון.

**חוק 1, המיקום הפיזי לעולם לא זז.**
הטוגל נשאר באותה פינה פיזית של המסך בכל שפה. לעגן עם `left` / `right` **פיזי**,
לעולם לא `inset-inline-start` / `inset-inline-end`: אלה מתהפכים עם `dir`
וגורמים לטוגל לקפוץ מפינה לפינה. כאן תכונה לוגית היא באג, לא פתרון.

**חוק 2, סדר הכפתורים לעולם לא משתנה.**
אם `EN` משמאל ו-`עב` מימין, כך זה נשאר גם בעברית וגם באנגלית.
בלי זה flexbox הופך את הסדר החזותי במעבר ל-RTL, והכפתור שמתחת לסמן משנה משמעות.

## המימוש הקנוני

```css
/* work-tokens.css */
.lang-toggle {
  direction: ltr;          /* נועל את סדר הכפתורים */
  unicode-bidi: isolate;   /* מבודד מאלגוריתם ה-bidi של ההורה */
}
```

```ts
/* i18n.ts, הסדר מוגדר פעם אחת בנתונים, לא נגזר מהשפה הפעילה */
export const LANG_ORDER: { code: Lang; label: string; aria: string }[] = [
  { code: "en", label: "EN", aria: "English" },
  { code: "he", label: "עב", aria: "Hebrew" },
]
```

ולמיקום, כשהטוגל לא בתוך שלד מקובע:
```css
position: absolute; top: 18px; left: 20px;  /* פיזי, לא inset-inline-* */
```

## הפתרון השורשי: עדיף על שניהם

לקבע את `<html>` ל-`dir="ltr"` ולהחיל `dir="rtl"` רק על מיכל התוכן.
אז השלד כולו (הדר, סיידבר, בורגר, טוגל) לא מתהפך מלכתחילה, פס הגלילה נשאר בימין,
ואין צורך בתיקונים נקודתיים.

## מה לא לעשות

`flex-direction: row-reverse` כדי "לסדר" את הכפתורים.
זה עובד עד שמשנים את סדר המערך, ואז נשבר בשקט. הסדר נקבע בנתונים, לא ב-CSS.

## בדיקה לפני מסירה

לפתוח בדפדפן אמיתי, להחליף שפה הלוך ושוב,
ולוודא שהטוגל לא זז ולו פיקסל אחד ושסדר הכפתורים זהה. בילד ירוק אינו הוכחה.
