# דף הסקריפט: "מה לומר בכל שקף"

מקור: `passover-script.html` של מצגת פסח 2026.

זה **החלק החשוב ביותר** במוצר. המצגת יפה, אבל הדף הזה הוא מה שהפך ילד
למישהו שיודע להציג. בלעדיו יש רק שקפים.

## העיקרון המרכזי

> **ההוראות בשפת האם של הילד. הטקסט להצגה בשפת ההצגה.**

הדף כולו `<html lang="he" dir="rtl">`: הכותרות, הטיפים וההסברים בעברית.
הטקסט שהילד באמת אומר על הבמה, באנגלית, בתוך קופסה נפרדת.
ככה הוא **מבין** מה נדרש ממנו, ולא רק **קורא** משהו זר.

   תת-כותרת: "קרא את הטקסט שלוש פעמים, תרגל בקול, ותהיה הכוכב של הכיתה! ⭐"

💡 קופסת טיפים כללית (כחול כהה, לפני הכל)

## התאמת הצבעים: לא קישוט

לכל כרטיס בדף הסקריפט יש `header` בגרדיאנט **הזהה** לרקע השקף המקביל:

```css
.h1 { background: linear-gradient(135deg, #1B2A6B, #0f1a45); }  /* = #s1 */
.h3 { background: linear-gradient(135deg, #3E2010, #1a0f08); }  /* = #s3 */
.h5 { background: linear-gradient(135deg, #0D47A1, #006064); }  /* = #s5 */
.h9 { background: linear-gradient(135deg, #1B5E20, #004D40); }  /* = #s9 */
```

הילד מרים עיניים למסך, מוריד אותן לדף, ומוצא את המקום לפי **צבע**, לא לפי מספר.
זה עובד גם כשהוא לחוץ.

## הטקסט: הסימון הוא הוראת ביצוע

```html
<div class="script-text">
"Hi everyone! My name is <strong>[Name]</strong>, and today I'm going to tell you <strong>an amazing story</strong>.

It happened a long, long time ago — <em>more than 3,000 years ago!</em>

It's the story of a whole people — the Jewish people — who were <strong>slaves in Egypt</strong>...
and how they finally became <strong>FREE</strong>."
</div>
```

```css
.script-text { white-space: pre-line; }              /* שורות ריקות = נשימות */
.script-text strong { background:#FFF3CD; padding:1px 4px; border-radius:4px; font-weight:900; }
.script-text em     { color:#1B2A6B; font-style:normal; font-weight:700; }
```

- **`<strong>`**: הדגשה צהובה → **להגיד חזק יותר**
- **`<em>`**: כחול מודגש → **להגיד לאט ובמשמעות**
- **שורה ריקה**: מקום לנשום. הטקסט לא נכתב בפסקאות אלא בשורות דיבור.
- **`CAPS`** בתוך הטקסט (`FREE`, `REALLY fast`), צעקה ממש.

## טיפי הביצוע: אוצר מילים קבוע

```html
<div class="slide-tip">
  <span class="st-icon">⏸️</span>
  עצור אחרי המילה "FREE", תן לה להישמע חזק. זה הרגע להביט בקהל.
</div>
```

| אייקון | משמעות | דוגמה אמיתית |
| :-: | :-- | :-- |
| ⏸️ | לעצור | "עצור אחרי 'But then, something changed', תן לקהל להתחיל לתהות!" |
| 🗣️ | להגביר קול | "אמור 'Freedom' בקול חזק וגאה, זה הכי חשוב!" |
| 🎭 | לשחק / לשנות קול | "כשאתה מחקה את פרעה, שנה קול, כאילו אתה שחקן." |
| 😄 | כאן בדיחה | "'The original fast food!', תגיד את זה כאילו אתה ממציא בדיחה." |
| ☝️ 👆 | להצביע על המסך | "בזמן שאתה מונה את המכות, הצבע על האייקונים אחד אחד." |
| 🎤 | להפעיל את הקהל | "כשאתה אומר 'say it with me!', חכה רגע שהכיתה תגיד! זה הרגע הכי כיפי." |
| 👀 | קשר עין | "הסתכל על הקהל, לא על המסך בלבד." |

**כלל:** לפחות טיפ אחד לכל כרטיס חייב להיות על **דינמיקה** (⏸️/🗣️/🎭) ולא רק על תנועה.
זה מה שהופך קריאה להצגה.

## משפט המפתח

קופסה מקווקוות בתחתית כל כרטיס, משפט אחד, המשפט שאם הכל נשכח, אומרים אותו:

```html
<div class="key-phrase">
  <span class="kp-icon">⭐</span>
  <div>
    <span class="kp-label">משפט המפתח</span>
    "Four hundred years of slavery. <strong>That's about to change.</strong>"
  </div>
</div>
```

בשקף האחרון ה-label משתנה ל־"משפט סיום":
`"Thank you for listening — and Happy Passover! 🌿"`

## קופסת הטיפים הכללית (5 טיפים, לא יותר)

1. 🗣️ דבר **לאט ובקול רם**: לא רץ, לא לוחש. כאילו אתה מספר סיפור לחבר.
2. 👀 הסתכל על **הקהל**, לא על המסך בלבד.
3. ⏸️ עצור שנייה אחרי משפטים חשובים, זה גורם להם **להישמע מדהים**.
4. 😊 אם שכחת משהו, **לא נורא!** אמור "and also…" והמשך.
5. 🎯 תרגל כל שקף **שלוש פעמים** בקול לפני ההצגה.

טיפ 4 הוא הכי חשוב: הוא מוריד את החרדה מראש.

**"לא צריך לשנן מילה במילה"**: לא לוותר על המשפט הזה. הוא ההבדל בין ילד שמדקלם לילד שמספר.

## הדפסה

הדף נועד להיות מודפס ולהחזיק ביד:

```css
.slide-card { page-break-inside: avoid; }
@media print {
  body { background:#fff; padding:16px; }
  .slide-card { box-shadow:none; border:1px solid #ddd; }
  .tips-box, .slide-header { -webkit-print-color-adjust: exact; print-color-adjust: exact; }
}
```
`print-color-adjust: exact` הכרחי, בלעדיו הכותרות הצבועות יוצאות לבנות והקישור לצבע נשבר.

## לתקן בפעם הבאה

```css
/* היה: */  .script-text { border-right: 4px solid #F5A623; }
/* צריך: */ .script-text { border-inline-start: 4px solid #F5A623; }
```
הדף RTL, ולכן תכונה לוגית היא הנכונה.
