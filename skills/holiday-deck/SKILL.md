# מצגת חג לילדים: הסגנון של פסח 2026

הסגנון הזה כבר עבד. הוא נבנה, הוצג בכיתה, והתקבל בדיוק כמו שרצו.
**אל תמציא סגנון חדש, שחזר את זה עם תוכן החג הנוכחי.**

> **הסקיל הזה יורש מ-`presentation-craft`.** שני עקרונות העל, מעט מאוד טקסט על השקף,
> ותמיד מסמך מלווה נפרד עם טונציה, מוגדרים שם ותקפים גם כאן. כאן נמצא רק מה שספציפי
> למצגת חג לילדים.

**מימוש הייחוס:** מצגת פסח 2026, חיה ב-`https://passover-2026.vercel.app`.
לפני שכותבים שורת קוד, לפתוח את המקור של העמוד ולהעתיק ממנו את השלד.

2. **שקף = רעיון אחד.** מקסימום 3 שורות תמיכה, כל אחת עד ~6 מילים. **מל"ל אפס.**
   כל הנרטיב חי בדף הסקריפט, לא על המסך.
3. **אלמנט אינטראקטיבי אחד ויחיד** במצגת, לא שניים. הוא הפסגה הדרמטית.

6. **אימוג'י הוא האיור.** לא clip-art, לא stock photos. תמונה אמיתית רק כשאימוג'י באמת לא מספיק (בפסח: קערת הסדר בלבד).

## עיצוב

**פונטים, שניים בלבד:**
`Fredoka One` לכל כותרת · `Nunito` (400/700/800/900) לכל השאר.
בדף הסקריפט: `Heebo` לעברית + `Fredoka One` לכותרות.

**כל גודל טקסט הוא `clamp()`.** אף פעם לא px קבוע. אין media query לטיפוגרפיה, רק אחד ב-600px שהופך flex-row לעמודה.

**כל שקף הוא שדה צבע מלא-מסך** עם gradient משלו + שתי הילות אור ב-`::before`:
```css
#s3 { background: linear-gradient(160deg, #2C1810 0%, #1a0f08 60%, #0d0806 100%); }
#s3::before {
  background:
    radial-gradient(ellipse 70% 50% at 20% 50%, rgba(139,90,43,.3) 0%, transparent 60%),
    radial-gradient(ellipse 40% 60% at 90% 20%, rgba(200,100,20,.15) 0%, transparent 60%);
}
```

**צבע = רגש.** לא פלטה אחידה, כל שקף בצבע של מה שקורה בו:
כחול כהה = פתיחה חגיגית · חרדל = הסבר · חום כהה = סבל · סגול-שחור = איום ·
כחול-טורקיז = גאולה · כתום = אוכל וחום · זהב = חפץ מרכזי · סגול-ורוד = שפה · ירוק = ניצחון.

**קלפים:** `border-radius: 20-24px`, צל כפול,
`box-shadow: 0 8px 0 rgba(0,0,0,.2), 0 20px 40px rgba(0,0,0,.15)` (צל קשה = מראה "צעצוע"),
hover = `translateY(-6px) rotate(-1deg)` (וזוגיים מסתובבים לכיוון ההפוך).

**אימוג'י גיבור:** `font-size: clamp(100px, 18vw, 180px)`, `filter: drop-shadow(0 20px 40px rgba(0,0,0,.4))`,
ותמיד אנימציית idle איטית 3-4 שניות `infinite`: float / sway / bounce. אף פעם לא סטטי.

**מעבר בין שקפים:**
```css
transform: translateX(60px) scale(.97);   /* נכנס */
transition: opacity .55s cubic-bezier(.4,0,.2,1), transform .55s cubic-bezier(.4,0,.2,1);
.exit { transform: translateX(-60px) scale(.97); }  /* יוצא, .35s */
```

**ניווט, ארבע דרכים במקביל**, כי מקרינים מכל מיני מכשירים:
חצים בצדדים · נקודות למטה · מקלדת (←/→/רווח) · swipe במגע.
בנוסף: מונה `1 / 9` בפינה ורמז `← → KEYS or SWIPE`.

פרטי מימוש מלאים: `references/deck-patterns.md`

## הפסגה האינטראקטיבית (שקף 4)

הלב של המצגת. בפסח: 10 המכות. הדפוס:

- רשת של פריטים **מוסתרים** (`opacity: 0; transform: scale(.5) rotate(-10deg)`).
- כל קליק חושף פריט **וגם** פותח **overlay מלא-מסך** עם:
  צבע רקע ייעודי · כותרת ענקית שקופצת (`cubic-bezier(.34,1.56,.64,1)`) · **מערכת חלקיקים**.
- הפריטים הם **data**, לא HTML:
  `{ icon, name, anim:{ bg, label, color, type, emoji[], count } }`
- ארבעה סוגי תנועה + חריג אחד:
  `rain` (נופל מלמעלה) · `jump` (קופץ מלמטה) · `swarm` (נחיל מרחף) · `float` (עולה לאט) · `dark` (בלי חלקיקים, רק הבהוב).
- **האינטראקציה חוטפת את הניווט:** בשקף הזה `→` ורווח מקדמים פריט, לא שקף. יוצאים מהשקף → reset.

לחג אחר: אותו מנוע בדיוק, תוכן אחר.
חנוכה → 8 נרות שנדלקים אחד-אחד · פורים → דמויות המגילה · סוכות → 7 אושפיזין.

## דף הסקריפט: "מה לומר בכל שקף"

**זה החלק שאף אחד אחר לא עושה, וזה מה שהפך את זה לעובד.**

- `<html lang="he" dir="rtl">`: **ההוראות בשפת האם של הילד, הטקסט להצגה בשפת ההצגה.**
- כרטיס אחד לכל שקף. **הכותרת של הכרטיס צבועה בדיוק בגרדיאנט של השקף**: הילד מתאים דף למסך במבט.
- כל כרטיס מכיל שלושה חלקים קבועים:
  1. **מה לומר**: טקסט מילה-במילה, שורות קצרות, שורה ריקה בין רעיונות (`white-space: pre-line`).
  2. **2-3 טיפים**: איך להגיד, לא מה.
  3. **⭐ משפט המפתח**: משפט אחד שאם שוכחים הכל, אומרים אותו.

**הסימון בטקסט הוא הוראת ביצוע**: משקל ויזואלי = משקל קולי:
- `<strong>` → הדגשה צהובה = **להגיד חזק יותר**
- `<em>` → כחול מודגש = **להגיד במשמעות, לאט**

**אוצר מילים קבוע לאייקוני הטיפים**: תמיד אותם, כדי שהילד ילמד אותם פעם אחת:

| אייקון | משמעות |
| :-: | :-- |
| ⏸️ | לעצור כאן, לתת למשפט לשקוע |
| 🗣️ | להגביר את הקול |
| 🎭 | לשנות קול / לשחק דמות |
| 😄 | כאן הבדיחה, להגיד אותה כאילו המצאת אותה עכשיו |
| ☝️ 👆 | להצביע על המסך |
| 🎤 | להפעיל את הקהל, לחכות שהם יגידו |
| 👀 | להסתכל בקהל |

**קופסת טיפים כללית בראש הדף** (5 טיפים): לאט ובקול · להסתכל בקהל · לעצור אחרי משפט חשוב · אם שכחת תגיד "and also…" ותמשיך · לתרגל כל שקף 3 פעמים.

**קופסת סיום:** "לא צריך לשנן מילה במילה, תבין את הסיפור ותספר אותו בדרך שלך."

**הדף מיועד להדפסה:** `@media print` + `page-break-inside: avoid` על כל כרטיס + `print-color-adjust: exact`.

תבנית מלאה: `references/script-page.md`

## התאמה לגן (גילאי 3-6): ראש השנה 2026

הקשת של 9 השקפים נכתבה לגילאי 5-11. לגן היא **מתקצרת ומשתנה**, ובצדק:

- **8 שקפים, לא 9.** בגן קשב של 20 שניות, כל שקף נוסף נגבה מחיר.
- **בלי "פרק החושך".** לחלק מהחגים אין קונפליקט (ראש השנה, שבועות, ט"ו בשבט),
  ובגיל הזה גם אין צורך. במקומו: שקף **רפלקטיבי-רך**: "מילים טובות", "מה נאחל".
- **שאלה או פעולה כל 2-3 משפטים.** זה החוק החשוב ביותר בגן.
  בדף הסקריפט לסמן כל אחת מהן ב-🎤, הן העוגן של כל השקף.
- **טריוויה מקוצרת:** 8 שאלות במקום 12, **תשובות באימוג'י גדול** ומינימום קריאה.
- **הגוף מסביר יותר טוב מהמילים.** בדף הסקריפט לתת טיפי 🎭 של תנועה ממש,
  "פרוש ידיים כשאתה אומר long, עשה עיגול כשאתה אומר round".

**כפתור "הקראה" (SpeechSynthesis)**: שייך ל**דף הסקריפט**, לא לשקף.
הצעות תוכן (למשל של Gemini) נוטות לשים אותו על השקף יחד עם טקסט המורה;
זה סותר את עקרון "מעט מאוד טקסט על השקף". מקומו ליד הטקסט שהוא מקריא.
`rate: 0.85`: איטי, כי זה נועד לגילאי 3-6.

**אינטראקציות בגן:** overlay מלא-מסך עדיין **אחד בלבד** (בראש השנה: פיצוץ גרגרי הרימון),
אבל *כן* כדאי תגובות-לחיצה קלות בתוך שקפים נוספים (שופר שמשמיע צליל, תפוח שנטבל בדבש).
בגיל הזה מגע הוא איך שלומדים.

## מה לתקן בפעם הבאה

הדברים האלה עבדו בפסח אבל לא נכונים, לא להעתיק אותם:

- **`border-right` בכרטיסי הסקריפט** → צריך `border-inline-start`. הדף RTL, אז תכונה לוגית היא הנכונה.
- **`Question 1 of 7`** מקודד קשיח ב-HTML של הטריוויה בזמן שיש 12 שאלות (ה-JS דורס את זה מיד, אבל למה להשאיר).
- **`score-number` מקודד `${total}/${total}`** במקום הציון האמיתי. זו הייתה החלטה מכוונת ("כולם מנצחים"), לשמור את ההתנהגות, אבל לכתוב אותה במפורש ולא כאילו זה באג.
- **חצים בניווט הם `←` ו-`→` פיזיים**: במצגת אנגלית זה נכון. **במצגת עברית להפוך את הכיוונים** לפי הסקיל `rtl-hebrew`.
